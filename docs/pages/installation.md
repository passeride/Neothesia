# Installation

## How to download

### Windows, MacOS, Ubuntu

Download Tangent from the [GitHub Actions artifacts](https://github.com/passeride/Neothesia/actions), or the **Assets** section of [Releases](https://github.com/passeride/Neothesia/releases) when a Tangent release is published.

Windows uses `tangent.exe`, Linux uses `tangent`, and macOS uses `Tangent.app`.
The existing upstream Neothesia packages on Flathub and AUR are separate from this fork.
The repository URL still contains Neothesia; the application is named Tangent.

## How to run

### On Mac

- Extract
- Right click + open

### On Windows/Linux

- Extract and double click

#### How to get working audio out

(on MacOS audio out is included out of the box)

- Download [default.sf2](https://github.com/passeride/Neothesia/blob/master/default.sf2)
- On Windows:
    - Place `default.sf2` in the same dir as executable (to make it a default one)
- On Linux:
    - Place `default.sf2` in the Tangent configuration directory `~/.config/tangent` (to make it a default one)
- Or select any sf2 file from the in-app menu
